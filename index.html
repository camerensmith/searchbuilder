Exclusions

Search filters

Uses Google's tbs parameter. Bing will just ignore this and use the same query. Google mostly ignores AND. Standard mode uses implicit AND (space).

💡 Tips & Keyboard Shortcuts

Keyboard Shortcuts:
  • Ctrl/Cmd + Enter - Run search
  • Ctrl/Cmd + K - Focus job titles (overrides browser default)
  • Ctrl/Cmd + S - Save query
Pro Tips:
  • Use Export/Import to backup your saved queries
  • Click exclusion chips to toggle them on/off
  • Save commonly-used job board URLs as bookmarks
  • Query preview updates live with 300ms debounce
